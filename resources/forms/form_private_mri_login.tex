This form contains administration information for the MRI Control Room and Computer.

\section{Keybox Code}

6875 (last digits of system ID)

\section{Kiosk Mode}

Toggle in/out of kiosk mode via: Tab + Del + `Send To'

Credentials for XA software:

\begin{enumerate}
    \item U: medadmin P: adm\$pwd\$4\$med\$
    \item U: clinadmin P: clin\$pwd\$4\$med\$
    \item U: medclient P: client\$pwd\$4\$med\$
\end{enumerate}

\section{Windows Mode}

Ctrl + Esc

\section{Reset Password}

\begin{enumerate}
    \item Log in as medadmin
    \item Open `myExam Cockpit'
    \item Select `Password Protection'
\end{enumerate}

Old passwords will be loaded automatically, and it will be possible to set a new password.

\section{Add DVS}

Add DVS to appropriate location:

\begin{enumerate}
    \item Enter Windows mode
    \item K:
    \item CustomerSeq
    \item DiffusionVectorSets
\end{enumerate}

Reference DVS in protocol:

\begin{enumerate}
    \item Protocol Card
    \item Diff
    \item Diffusion Mode
    \item Free
\end{enumerate}
