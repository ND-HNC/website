\textbf{Section 6. Instructions for MRI preparation.}

\begin{enumerate}
    \item Remove all jewelry (e.g. necklace, watch, rings).
    \item Remove all hair pins, bobby pins, barrettes, clips, etc.
    \item Remove all body piercings.
    \item Remove dentures, false teeth, partial dental plates.
    \item Remove eyeglasses and hearing aids.
    \item Remove bra which contain metallic underwires or clasps/adjusters.
    \item Change into provided scrubs.
    \item Leave all personal items with your clothes (e.g. cell phones, credit cards).
    \item If you are unable to remove any of the above items please notify the MRI technologist.
\end{enumerate}
